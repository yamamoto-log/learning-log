  * `.gitkeep` を使った空フォルダの管理方法

* **学んだこと・メモ**
  * 空フォルダは Git の追跡対象外になるため `.gitkeep` が必要。
  * `git status` で緑色のファイル（`renamed:` など）は `git add` 不要で直接コミット可能。
  * 現在地（カレントディレクトリ）を `pwd` やプロンプトでしっかり確認してからコマンドを叩く。
